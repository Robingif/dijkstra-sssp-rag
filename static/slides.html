Dijkstra's Shortest Path Algorithm

Single-Source Shortest Path (SSSP) on Weighted Graphs • Grounded in GeeksforGeeks & MIT 6.006

🎯 The Problem

Find shortest paths from a single source node to all other vertices in a directed or undirected graph with non-negative edge weights.

⚡ Greedy Paradigm

Greedily finalizes the closest unvisited vertex at each step, guaranteeing global optimality via edge relaxation.

🌐 Applications

Drives the Internet's core routing via OSPF, powers Google Maps / GPS navigation, and guides autonomous vehicle pathfinding.

FOUNDATIONS

1. Problem Formulation & Edge Relaxation

How Distance Estimates Converge to True Shortest Distances

Mathematical Model

Graph G = (V, E) with w(u, v) ≥ 0: • d[v]: Tentative shortest-path estimate • π[v]: Predecessor vertex • δ(s, v): True minimum distance.

Relaxation Step

Relax(u, v, w): if d[v] > d[u] + w(u, v): d[v] = d[u] + w(u, v) π[v] = u Lowers upper bound when a shorter path is found!

MIT 6.006 Invariants

• Upper-Bound: d[v] ≥ δ(s, v) always • Triangle Inequality: δ(s, v) ≤ δ(s, u) + w(u, v) • Convergence: Once d[u] is optimal, relaxing (u, v) optimizes d[v].

MECHANICS

2. Greedy Invariant & Shortest Path Tree

Why Greed Guarantees Global Optimality for Non-Negative Weights

Vertex Partitions

1. Visited Set (S): Vertices whose shortest distance is finalized: d[u] = δ(s, u). 2. Priority Queue (Q): Vertices awaiting finalization, keyed by d[v].

Algorithm Loop

1. Initialize d[s] = 0, others = inf. 2. While Q is not empty: a. u = Extract-Min(Q) b. Add u to S. c. For each neighbor v: Relax(u, v, w).

Shortest Path Tree

Predecessor pointers π[v] form a directed spanning tree rooted at source s. Tracing backwards yields the exact sequence of vertices.

REPRESENTATION 1

3. Adjacency Matrix Implementation — O(V²)

Simplicity and Optimality for Dense Graphs (GeeksforGeeks)

How it Works

• Graph stored as V x V 2D matrix. • Finding minimum distance vertex requires a linear scan of V elements in O(V). • Total Time: V × O(V) = O(V²).

Space & Complexity

• Time: O(V²) • Space: O(V²) for matrix, O(V) auxiliary. • Optimal for dense graphs where E ≈ V².

When to Avoid

For sparse networks (roads, social graphs with E = O(V)), scanning all V vertices at every step wastefully inspects non-existent edges.

REPRESENTATION 2

4. Adjacency List + Min-Heap — O((V + E) log V)

The Production Standard for Sparse Networks (GeeksforGeeks)

Heap Optimization

• Graph stored as adjacency list. • Tentative distances kept in a Min-Heap. • Extract-Min drops from O(V) to O(log V)! • Edge relaxation takes O(log V).

Lazy Deletion

• Push (new_dist, v) into the heap on relaxation. • Discard stale entries upon popping if current_dist > dist[v]. • Maintains identical O((V + E) log V) bound!

Real-World Speedup

For V = 100,000, E = 300,000: • Matrix: 10,000,000,000 ops (~10s) • Min-Heap: 6,600,000 ops (<0.01s) → Over 1,500x faster!

C++ STL OPTIMIZATION

5. Using std::set in C++ (Balanced BST)

Emulating Decrease-Key without Redundant Heap Growth

Why std::set?

• std::priority_queue does not support arbitrary deletion. • std::set (Red-Black Tree) supports erase() in O(log N).

Dynamic Update

if (dist[v] != INF) st.erase(st.find({dist[v], v})); dist[v] = dist[u] + weight; st.insert({dist[v], v}); Purges old entries immediately!

Strict O(V) Space

The set contains at most V elements at all times, preventing heap bloat up to E elements in memory-constrained devices.

THEORETICAL LIMITS

6. Why Dijkstra Fails on Negative Weights

Greedy Invariant Breakdown & Counterexample

The Fatal Flaw

• Assumes path weights only grow with more hops. • Negative edges allow a path to decrease. • Once a node is finalized, Dijkstra never re-evaluates it!

3-Node Counterexample

Edges: (A, B)=5, (A, C)=2, (B, C)= -6 • Dijkstra finalizes C first with dist[C] = 2. • Later A → B → C = 5 - 6 = -1. • Misses the true shortest path (-1)!

What to Use Instead

• Bellman-Ford: O(V · E), detects negative cycles. • DAGs: Topological sort relaxation in O(V + E).

8. Key Algorithmic Insights & Takeaways

The Complete Decision Guide for Engineers

Optimal Choice

• Dense graphs (E ≈ V²): Adjacency Matrix O(V²). • Sparse graphs (E ≪ V²): Adjacency List + Min-Heap O((V + E) log V).

Cardinal Rule

All edge weights MUST be non-negative (w(e) ≥ 0). If negative edges exist, use Bellman-Ford O(V · E).
