⚠️ Visual 2: The 3-Node Counterexample (Why Dijkstra Fails on Negative Edges)

Greedy Invariant Violation

Dijkstra assumes paths grow monotonically. Because node A has distance 3 and node B has distance 5, Dijkstra finalizes A first. But the subsequent negative edge (B ➔ A with weight -4) reduces the path to 1, causing Dijkstra to report the wrong answer (3 instead of 1).

⚡ Visual 3: Adjacency Matrix O(V²) vs Min-Heap O((V+E) log V) Architecture

Data Structure Trade-Off

Comparing memory layout and asymptotic runtimes across graph density topologies.

🟦 Adjacency Matrix (Dense Graphs)
• Data Structure: 2D Array matrix[V][V]
• Time Complexity: O(V²)
• Space Complexity: O(V²)
• Find Min Vertex: Linear scan over V unvisited nodes = O(V)
• Relaxation: Check all row elements = O(V)
• Best Used For: Dense graphs where E ≈ V² (no priority queue overhead).
🌲 Min-Heap + Adjacency List (Sparse Graphs)
• Data Structure: Binary Heap (e.g. Python heapq)
• Time Complexity: O((V + E) log V)
• Space Complexity: O(V + E)
• Find Min Vertex: extract_min() = O(log V)
• Relaxation: decrease_key() or lazy push = O(log V)
• Best Used For: Road networks, Google Maps, GPS, internet topologies (E ≪ V²).

🌐 Visual 4: Shortest Path Tree (SPT) & Frontier Partition (MIT 6.006)

Cut Property & Invariant

At any stage during Dijkstra's algorithm, vertices are divided into two disjoint sets: S (finalized shortest paths) and V - S (unvisited / frontier nodes). Because non-negative edges ensure sub-paths only grow, the edge crossing the cut with the minimum tentative value is guaranteed optimal.

Finalized Set S (Known δ(s, u)):
• Vertices whose shortest distance is permanently proven.
• Invariant: d[u] = δ(s, u) for all u ∈ S.
• Never modified or popped from the priority queue again.
Frontier Set V - S (Tentative Bounds):
• Vertices still in the Min-Heap.
• d[v] is an upper bound on true distance.
• Vertex with min(d[v]) across the boundary is safely moved to S.
